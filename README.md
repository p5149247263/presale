# AI Presales Copilot

End-to-end presales automation tool for AI/ML/GenAI opportunities.

## What it includes
- FastAPI backend with modular agents
- React frontend workflow
- Citation-first RAG model and traceability objects
- Runtime LLM provider selection (`mock/openai/anthropic/local`)
- Requirement matrix, architecture options, cloud/cost/risk recommendations
- Proposal generation to DOCX + PDF
- Brainstorming workspace and client clarifications list
- Security basics: RBAC, encrypted file store, audit log, optional PII redaction
- Sample RFP and KB artifacts
