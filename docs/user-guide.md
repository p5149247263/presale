# User Guide

1. Create a project and capture client notes/assumptions.
2. Upload RFP, annexures, and notes.
3. Run requirement extraction and review/approve matrix rows.
4. Generate architecture options and review Mermaid diagrams.
5. Generate cloud recommendation, cost estimate, and risk register.
6. Generate proposal and export DOCX/PDF paths.
7. Use brainstorming workspace for clarifications and opportunity discovery.
